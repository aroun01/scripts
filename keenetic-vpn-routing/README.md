# Исключения из VPN на Keenetic

Скрипт Entware добавляет IPv4-подсети из `amnezia-routes.txt` в таблицу маршрутизации VPN-политики, направляя их через провайдера. Остальной трафик в этой таблице использует существующий маршрут VPN по умолчанию. Список содержит исключения для российских сервисов, включая адреса MAX; он не является полным и нуждается в обновлении при изменении инфраструктуры сервисов.

## Установка и настройка

1. Сохраните резервные копии действующих файлов `/opt/etc/amnezia-add-routes.sh` и `/opt/etc/amnezia-routes.txt`.
2. Разместите файлы из этой папки в `/opt/etc/` и назначьте скрипту права на выполнение (`chmod +x /opt/etc/amnezia-add-routes.sh`).
3. В скрипте укажите подходящие `GW`, `IFACE` и `TABLE`: в опубликованном скрипте адрес шлюза заменён на `YOUR_ISP_GATEWAY`. Шлюз может измениться при переподключении. Таблица должна уже использоваться нужной политикой VPN и содержать маршрут по умолчанию через VPN.
4. Запустите `/opt/etc/amnezia-add-routes.sh add`. Проверить состояние можно командой `/opt/etc/amnezia-add-routes.sh check`, удалить маршруты из списка — командой с аргументом `del`. Скрипт пишет журнал в `/opt/var/log/amnezia-routes.log`.

Файл списка содержит по одной подсети CIDR на строку; строки с `#` и пустые строки игнорируются. Маршруты применяются ко всем клиентам соответствующей VPN-политики, а не только к одному устройству. Список включает широкие сети и общие адреса: весь трафик к ним пойдёт напрямую, включая другие сервисы в тех же сетях. IPv6 этим скриптом не обрабатывается. После изменения списка или сетевых параметров проверьте маршруты и доступность сервисов; для восстановления после перезагрузки настройте повторный запуск, например в cron.
